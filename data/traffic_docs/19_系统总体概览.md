# 城市轨道交通系统总体概览

> 来源：城市轨道交通综合公开技术资料
> 说明：本文档为技术整理稿，仅用于本地 RAG 系统技术验证。

## 系统构成

城市轨道交通系统由多个专业子系统协同构成，主要包括：

| 子系统 | 主要功能 |
|---|---|
| 车辆系统 | 承载乘客，提供牵引动力 |
| 信号系统（CBTC） | 列车运行控制、安全防护、调度 |
| 通信系统 | 语音、数据、图像传输 |
| 供电系统 | 为列车及车站设备提供电能 |
| 轨道系统 | 承载列车运行 |
| 机电系统 | 通风空调、给排水、AFC、FAS、PIS、站台门等 |
| 综合监控系统（ISCS） | 集成监控各子系统 |

## 核心专业子系统职责

### 信号系统（CBTC）
采用移动闭塞，通过 ATP/ATO/ATS 三层架构实现列车的安全防护、自动运行与调度监控。

### 供电系统
采用直流 1500V/750V 制式，由牵引变电所经整流机组将交流电整流为直流电，通过接触网或第三轨向列车供电。

### 车辆系统
按列检、月检、架修、大修（或列检、月检、定修、架修 A/B、厂修）分级检修。

## 运行维护总体要求

根据《城市轨道交通设施设备运行维护管理办法》，运营单位应：

1. 组织编制设施设备维护规程，报主管部门备案；
2. 根据维护规程编制维护计划并组织实施；
3. 制定并落实施工检修制度，做好施工安全管理；
4. 利用设备自有监测诊断功能，对关键部位实时监控；
5. 定期校准各设备系统时钟，确保与主时钟服务器同步；
6. 保障每天非运营时间检修施工预留时间不少于 4 小时。

## 应急管理总体要求

运营单位是运营突发事件处置工作的责任主体，应建立健全应急指挥和协调联动机制，完善应急预案体系，做好客流疏散组织，建立信息共享和应急联动机制。
