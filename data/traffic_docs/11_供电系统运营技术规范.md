# 城市轨道交通供电系统运营技术规范要点

> 来源：《城市轨道交通供电系统运营技术规范（试行）》及供电系统公开技术资料
> 说明：本文档为技术整理稿，仅用于本地 RAG 系统技术验证。

## 系统构成

根据《城市轨道交通供电系统运营技术规范（试行）》，城市轨道交通供电系统主要包括：外部电源，以及牵引网、变配电、动力与照明、电力监控、杂散电流防护等子系统。

## 外部电源方案

外部电源采用集中式、分散式或混合式供电方案，通过城市电网 110kV/220kV 输电线路输入电能。

## 中压与低压分配

- 主变电所将 110kV/220kV 高压电降压为中压（35kV / 20kV / 10kV）；
- 牵引供电系统通过 24 脉波整流机组将中压交流转换为直流 1500V 或 750V，通过接触网为列车提供动力；
- 动力照明系统则降压为 380V/220V 供车站设备使用。

## 供电制式与关键参数

| 参数 | 值 |
|---|---|
| 供电制式 | 直流 750V / 1500V |
| 中压等级 | 35kV / 20kV / 10kV |
| 核心组件 | 牵引变电所、接触网、主变电所、降压变电所、电力监控系统 |
| 负荷分级 | 一级负荷双电源保障 |
| 防护体系 | 杂散电流监测与疏导 |
| 监控系统 | SCADA 自动化管理 |

## 供电连续性保障

系统采用**双电源互备机制**保障供电连续性，配备微机保护装置与电力监控实现远程调度。

## 智能供电发展趋势

新一代智能供电综合监控系统深度融合云计算与人工智能技术，实现供电设备远程监控、故障预警及智能运维。系统亦探索应用绿色能源，如在车辆基地建设光伏发电项目为运营提供补充电力。柔性直流供电技术基于全控型双向变流器和智能协同控制，可优化外电源配置、提升再生制动能量利用率、稳定网压。
