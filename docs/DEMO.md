# 演示脚本（DEMO）

> 5 个演示问题 + 预期输出 + 截图位置占位。
> **截图由你本人操作**：按下方「启动方式」启动 UI，截对应画面（记得给 API Key / 敏感信息打码）。

---

## 启动方式

```powershell
cd D:\google\kotaemon-main\kotaemon-main
.\.venv\Scripts\activate
python app.py        # 启动 Gradio Web UI，浏览器打开 http://localhost:7860
```

> 也可用命令行方式演示（不起 UI）：
> ```powershell
> python scripts\query_cli.py
> ```

## 5 个演示问题

> 每个问题选自我 125 条评测集（`eval/qa_set.jsonl`），覆盖 single_hop / numeric / multi_hop / table 不同类型。

### 演示 1（single_hop，条款号定位）

**问题**：信号系统的大修周期是多少年？

**预期输出**：
- 答案给出「大修不超过 **10 年**」
- 带条款号：第十三条第（二）项
- 带原文引用与文档出处：`13_信号系统维修分级与周期.md`

**截图位置**：`docs/images/demo_1_single_hop.png`（占位）

---

### 演示 2（numeric，数值精确匹配）

**问题**：车辆检修中，架修 A 的检修周期是行驶多少万公里或几年？

**预期输出**：
- 答案给出「架修 A：**120 万公里 / 4 年**」
- 出处：`04_车辆检修修程与周期.md`

**截图位置**：`docs/images/demo_2_numeric.png`（占位）

---

### 演示 3（multi_hop，跨文档推理）

**问题**：CBTC 无线通信中断降级为点式 ATP 后，列车运行限速是多少？这一限速要求与哪份行车规章中的疏散限速一致？

**预期输出**：
- 答案综合两个文档：降级后限速（如 25 km/h）与《行车组织管理办法》疏散限速一致
- 出处：`03_CBTC信号系统原理.md` + `01_行车组织管理办法_区间疏散与限速.md`

**截图位置**：`docs/images/demo_3_multi_hop.png`（占位）

---

### 演示 4（table，表格解析）

**问题**：《设施设备运行维护管理办法》第十二条、第十三条、第十四条、第十五条分别规定了什么？

**预期输出**：
- 答案按条分点列出：第十二条（维护规程编制与备案）、第十三条（维护要求）、第十四条（计划执行与检修时间）、第十五条（施工检修制度与安全）
- 出处：`02_设施设备运行维护管理办法_检修周期.md`（含表格）

**截图位置**：`docs/images/demo_4_table.png`（占位）

---

### 演示 5（边界：知识库外问题，不编造）

**问题**：请问明天北京地铁 4 号线首班车是几点？

**预期输出**：
- 明确回答「**未在知识库中检索到**」相关内容，不编造时刻表
- 体现领域 prompt 的"不确定就说不知道"约束

**截图位置**：`docs/images/demo_5_out_of_scope.png`（占位）
